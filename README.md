# BabyShow

Application Android conçue pour le Salon Baby afin de présenter les accompagnements de **Gaëlle — Accompagnante parentale**, proposer un quiz aux parents et faciliter la prise de contact.

## Télécharger l'application

La dernière version Android sera disponible dans la section **Releases** de ce dépôt sous la forme d'un fichier APK signé.

> Sur Android, l'installation d'un APK téléchargé en dehors du Play Store peut nécessiter d'autoriser temporairement l'installation d'applications provenant de votre navigateur ou de votre gestionnaire de fichiers.

## Fonctionnalités

- présentation claire des accompagnements proposés ;
- interface adaptée à une tablette de salon ;
- formulaire de contact utilisable hors ligne ;
- export local des contacts ;
- quiz parents ;
- installation sur Android sans passer par le Play Store.

## Compatibilité

Application Android développée avec Vite + Capacitor.

Identifiant Android :

`com.jhdsolutions.babyshow`

## À propos

BabyShow est développé pour **Gaëlle — Accompagnante parentale**, avec le support de **JHD Solutions**.
